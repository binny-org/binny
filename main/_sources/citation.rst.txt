|logo| Citation
===============

If you use **binny** in academic work, please cite it.

Citation metadata is provided in the ``CITATION.cff`` file at the root of the
repository. GitHub automatically uses this file to generate BibTeX and other
citation formats.

Recommended citation
--------------------

.. code-block:: text

   Nikolina Šarčević, Matthijs van der Wild, and Rebekah Polen.
   binny: Flexible binning algorithms for cosmology.
   Version 0.4.5, 2026.
   https://github.com/binny-org/binny

BibTeX
------

.. code-block:: bibtex

   @software{sarcevic_binny_2026,
     author = {Šarčević, Nikolina and van der Wild, Matthijs and Polen, Rebekah},
     title = {{binny}: Flexible binning algorithms for cosmology},
     version = {0.4.5},
     year = {2026},
     url = {https://github.com/binny-org/binny},
     license = {MIT}
   }
