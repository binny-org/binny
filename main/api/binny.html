class binny.Tomography(z: NDArray[~numpy.float64], nz: NDArray[~numpy.float64], bins: dict[int, NDArray[~numpy.float64]], metadata: dict[str, ~typing.Any] = <factory>, spec: dict[str, ~typing.Any] | None = None, survey_metadata: dict[str, ~typing.Any] = <factory>)#

Bases: object

Tomographic distributions evaluated on a common redshift grid.

Parameters:

  • z – True-redshift grid.

  • nz – Parent redshift distribution.

  • bins – Mapping from bin index to redshift distribution.

  • metadata – Numerical metadata and diagnostics associated with the tomographic binning. Defaults to an empty dictionary.

  • spec – Optional resolved tomography specification, including any configuration overrides. None when no specification was used.

  • survey_metadata – Optional survey-level metadata, including survey properties and provenance. Defaults to an empty dictionary.

Build tomography from a survey preset or configuration.

Parameters:

  • survey – Built-in survey name, such as "lsst" or "desi".

  • config_file – Path to a custom YAML file or shipped configuration.

  • cfg – Optional in-memory survey configuration.

  • z – Optional redshift grid overriding the configured grid.

  • role – Optional tomography role selector.

  • year – Optional survey year selector.

  • scenario – Optional scenario selector.

  • sample – Optional sample selector.

  • overrides – Optional tomography specification overrides. Nested mappings are merged one level deep.

  • include_survey_metadata – Whether to attach survey metadata.

  • include_tomo_metadata – Whether to include tomography metadata.

  • include_photoz_diagnostics – Whether to include photo-z diagnostics.

Returns:

Tomography containing the parent redshift distribution, bins, resolved specification, and requested metadata.

Raises:

  • ValueError – If configuration sources or tomography selection are invalid.

  • FileNotFoundError – If the requested configuration cannot be found.

binny.build_tomography(z: NDArray[float64], nz: NDArray[float64], edges: NDArray[float64], assignment: Callable[[NDArray[float64], NDArray[float64]], NDArray[float64]] | None = None, *, method: Literal['deterministic', 'specz', 'photoz'] | None = None, params: Mapping[str, Any] | None = None, selection_kind: Literal['probability', 'weight'] = 'probability', normalize_input: bool = False, normalize: bool = True, norm_method: Literal['trapezoid', 'simpson'] = 'trapezoid') → Tomography#

Build tomographic redshift distributions from a bin-assignment model.

Parameters:

  • z – True-redshift grid.

  • nz – Parent redshift distribution.

  • edges – Tomographic bin edges.

  • assignment – Optional custom assignment function returning an array of shape (n_bins, n_z).

  • method – Built-in assignment model: "deterministic", "specz", or "photoz". Defaults to "deterministic" when no custom assignment is provided.

  • params – Model-specific keyword arguments passed to the selected assignment function.

  • selection_kind – Whether selections represent probabilities or arbitrary non-negative weights.

  • normalize_input – Whether to normalize the parent distribution before constructing bins.

  • normalize – Whether to normalize individual bin distributions.

  • norm_method – Numerical integration method for normalization.

Returns:

Tomography result containing bin distributions and metadata.

Raises:

  • ValueError – If method and assignment conflict or the method is unknown.

  • TypeError – If model parameters are invalid.

  • predefined_bins – Optional mapping of externally supplied bin distributions for predefined tomography.

  • include_tomo_metadata – Whether to include numerical binning metadata.

binny.sample_mock_catalog_from_nz(z: Any, nz: Any, n_samples: int, *, observation_model: Callable[[NDArray[float64], Generator], NDArray[float64]] | None = None, weights: Any | None = None, seed: int | None = None, rng: Generator | None = None) → dict[str, NDArray[float64]]#

Generate a mock redshift catalog from a tabulated distribution.

Redshifts are sampled from the supplied distribution without assuming a particular measurement technique. An optional callable can generate observed redshifts from the sampled values.

The observation model must accept (z_samples, rng) and return one finite observed redshift per input sample. This permits photo-z, spec-z, grism, narrow-band, or user-defined measurement models.

Parameters:

  • z – Strictly increasing one-dimensional redshift grid.

  • nz – Nonnegative distribution evaluated on z.

  • n_samples – Number of catalog objects to generate.

  • observation_model – Optional callable accepting sampled redshifts and a NumPy random generator, returning observed redshifts. The input distribution must represent the underlying redshift population appropriate for this model.

  • weights – Optional scalar or one-dimensional array of object weights. Defaults to unit weights.

  • seed – Optional random seed for reproducibility.

  • rng – Optional NumPy random generator. Cannot be combined with seed.

Returns:

Dictionary containing z and weight. When an observation model is provided, also contains z_obs. The z values represent the distribution supplied by the caller; they are interpreted as true redshifts only when the input distribution is a true-redshift distribution.

Raises:

  • TypeError – If the sample count, random generator, or observation model has an invalid type.

  • ValueError – If the distribution, weights, or observed redshifts are invalid.

binny.sample_redshifts_from_nz(z: Any, nz: Any, n_samples: int, *, seed: int | None = None, rng: Generator | None = None) → NDArray[float64]#

Sample continuous redshifts from a tabulated redshift distribution.

The distribution is interpreted as piecewise linear between grid points. Sampling uses inverse-CDF sampling with exact inversion within each interval, including on nonuniform grids. The input is normalized internally and may represent any redshift distribution.

Parameters:

  • z – Strictly increasing one-dimensional redshift grid.

  • nz – Nonnegative distribution evaluated on z.

  • n_samples – Number of redshifts to generate.

  • seed – Optional random seed for reproducibility.

  • rng – Optional NumPy random generator. Cannot be combined with seed.

Returns:

One-dimensional array of sampled redshifts within the input grid.

Raises:

  • TypeError – If n_samples or rng has an invalid type.

  • ValueError – If the distribution is invalid or has zero integral.
